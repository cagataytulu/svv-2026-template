# SVV 2026 — Personal Project Template

This is the starting point for your semester-long V&V project.

## First-time setup
```
git clone https://github.com/cagataytulu/svv-2026-template.git
cd svv-2026-template
python seed_bugs.py <your_student_id>
```

This generates `student_build/<your_student_id>/` — your own personal,
uniquely-buggy codebase. From now on, write your tests against the code
inside that folder.

See the Week 1 and Week 3 course materials on Google Classroom for full
instructions.
